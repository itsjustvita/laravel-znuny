# laravel-znuny v0.2.0 (Generic Znuny Support) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make laravel-znuny work out of the box with any Znuny installation (stock `GenericTicketConnectorREST`) through configurable routes and auth, add a generic `call()` API, better error mapping, ticket features, webhooks and CI, and release `v0.2.0`.

**Architecture:** A validated per-connection `ConnectionConfig` holds a `RouteMap` (presets + overrides) and the auth settings. `RequestBuilder` turns `(operation, payload, auth)` into a `PreparedRequest` (method, URL with Znuny-style query string, JSON body, `X-OTRS-Header-*` headers). `ZnunyClient::call()` is the single entry point: it adds session or credential auth, dispatches through Laravel's HTTP client, maps failures with `ExceptionMapper::fromResponse()` and emits events/logs through a shared `Redactor`. Resources and builders only speak operation names.

**Tech Stack:** PHP 8.3+, Laravel 12/13 components (http, cache, events, console, routing, pagination, log), PHPUnit 12, Orchestra Testbench 10/11, Laravel Pint, GitHub Actions, Docker (Znuny 7.3.7 + MariaDB) for integration verification.

**Spec:** `docs/superpowers/specs/2026-10-09-generic-v0.2-design.md`

## Review Focus

1. A batched `TicketGet` that contains an unknown or inaccessible ID: Znuny rejects the whole batch with `TicketGet.AccessDenied`; `findMany()` must fall back to single requests and skip only the failing IDs (Task 11, `test_find_many_skips_tickets_that_znuny_denies`).
2. Searching on the default preset (`GET /Ticket`) with list filters must send repeated keys (`States=new&States=open`), and nested filters must fail before anything is sent (Task 5 and Task 11, `test_search_and_get_use_repeated_query_keys_and_one_batched_ticket_get`, `test_dynamic_field_search_on_get_route_fails_before_sending`).
3. A route misconfiguration (Znuny's plain-text HTTP 500 "Error while determine Operation") must raise `ZnunyRouteNotFoundException` after one request, not after three HTTP retries (Task 7, `test_missing_route_fails_fast_without_http_retries`; Task 13 at feature level).
4. Credentials mode with a wrong password must raise `ZnunyAuthenticationException` without a session re-login loop (Task 7, `test_credentials_mode_auth_fail_is_not_retried`).
5. Old published config files without `routes`/`auth` keys must fall back to the stock routes and session auth, and a missing `username`/`password` must raise `ZnunyConfigurationException` naming the key (Task 4, `test_minimal_config_uses_documented_defaults`, `test_missing_required_keys_throw`; Task 8, `test_incomplete_connection_config_throws_configuration_exception`).

`src/Support/Redactor.php`:

```php
<?php

namespace ItsJustVita\LaravelZnuny\Support;

final class Redactor
{
    public const REDACTED = '[REDACTED]';

    /** @var list<string> */
    private const SENSITIVE_KEYS = [
        'password', 'pw', 'userpw', 'newpw', 'sessionid', 'secret', 'token',
        'accesstoken', 'apikey', 'authorization', 'otp', 'twofactortoken',
        'x-otrs-header-password', 'x-otrs-header-sessionid',
    ];

    /**
     * Replace the values of sensitive keys (case-insensitive, at any depth) with [REDACTED].
     *
     * @param  array<array-key, mixed>  $data
     * @return array<array-key, mixed>
     */
    public static function redact(array $data): array
    {
        foreach ($data as $key => $value) {
            if (is_string($key) && in_array(strtolower($key), self::SENSITIVE_KEYS, true)) {
                $data[$key] = self::REDACTED;

                continue;
            }

            if (is_array($value)) {
                $data[$key] = self::redact($value);
            }
        }

        return $data;
    }

    /**
     * Redact secrets and shorten large "Content" values (base64 attachments) for log output.
     *
     * @param  array<array-key, mixed>  $data
     * @return array<array-key, mixed>
     */
    public static function forLog(array $data): array
    {
        return self::shortenContent(self::redact($data));
    }

    /**
     * @param  array<array-key, mixed>  $data
     * @return array<array-key, mixed>
     */
    private static function shortenContent(array $data): array
    {
        foreach ($data as $key => $value) {
            if (is_array($value)) {
                $data[$key] = self::shortenContent($value);
            } elseif ($key === 'Content' && is_string($value) && strlen($value) > 64) {
                $data[$key] = sprintf('[%d chars]', strlen($value));
            }
        }

        return $data;
    }
}
```

```php
namespace ItsJustVita\LaravelZnuny\Exceptions;

use ItsJustVita\LaravelZnuny\Support\Redactor;

abstract class ZnunyException extends RuntimeException

    protected string $operation = '';

    protected string $errorCode = '';

    protected string $connection = '';

    protected array $requestPayload = [];

    protected array $responseBody = [];

    protected ?int $httpStatus = null;

    public function setOperation(string $operation): static
    {
        $this->operation = $operation;

        return $this;
    }

    public function getOperation(): string
    {
        return $this->operation;
    }

    public function setErrorCode(string $code): static
    {
        $this->errorCode = $code;

        return $this;
    }

    public function getErrorCode(): string
    {
        return $this->errorCode;
    }

    public function setConnection(string $connection): static
    {
        $this->connection = $connection;

        return $this;
    }

    public function getConnection(): string
    {
        return $this->connection;
    }

    public function setRequestPayload(array $payload): static
    {
        $this->requestPayload = Redactor::redact($payload);

        return $this;
    }

    public function getRequestPayload(): array
    {
        return $this->requestPayload;
    }

    public function setResponseBody(array $body): static
    {
        $this->responseBody = $body;

        return $this;
    }

    public function getResponseBody(): array
    {
        return $this->responseBody;
    }

    public function setHttpStatus(?int $status): static
    {
        $this->httpStatus = $status;

        return $this;
    }

    public function getHttpStatus(): ?int
    {
        return $this->httpStatus;
    }

    public function context(): array
    {
        return [
            'znuny_operation' => $this->operation,
            'znuny_error_code' => $this->errorCode,
            'znuny_connection' => $this->connection,
            'znuny_http_status' => $this->httpStatus,
            'znuny_payload' => $this->requestPayload,
            'znuny_response' => $this->responseBody,
        ];
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\Routing;

use ItsJustVita\LaravelZnuny\Exceptions\ZnunyConfigurationException;
use Stringable;

final readonly class Route implements Stringable
{
    private const METHODS = ['GET', 'POST', 'PUT', 'PATCH', 'DELETE'];

    public function __construct(
        public string $method,
        public string $path,
    ) {}

    /**
     * Parse a definition in Znuny's admin notation, e.g. "GET /Ticket/:TicketID".
     * The method is optional and defaults to POST.
     */
    public static function parse(string $definition): self
    {
        $parts = preg_split('/\s+/', trim($definition), -1, PREG_SPLIT_NO_EMPTY) ?: [];

        if (count($parts) === 1) {
            array_unshift($parts, 'POST');
        }

        if (count($parts) !== 2) {
            throw new ZnunyConfigurationException(
                "Invalid route definition [{$definition}]. Expected \"METHOD /Path/:Param\"."
            );
        }

        $method = strtoupper($parts[0]);

        if (! in_array($method, self::METHODS, true)) {
            throw new ZnunyConfigurationException(
                "Invalid HTTP method [{$parts[0]}] in route definition [{$definition}]."
            );
        }

        return new self($method, '/'.ltrim($parts[1], '/'));
    }

    /**
     * Placeholder names in the path, e.g. ["TicketID"] for "/Ticket/:TicketID".
     *
     * @return list<string>
     */
    public function parameters(): array
    {
        preg_match_all('#:([^/]+)#', $this->path, $matches);

        return $matches[1];
    }

    /**
     * Znuny ignores request bodies on GET routes; everything else carries a JSON body.
     */
    public function sendsBody(): bool
    {
        return $this->method !== 'GET';
    }

    public function __toString(): string
    {
        return $this->method.' '.$this->path;
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\Routing;

use ItsJustVita\LaravelZnuny\Exceptions\ZnunyConfigurationException;

final class RouteMap
{
    /**
     * @param  array<string, Route>  $routes
     */
    public function __construct(
        private readonly array $routes,
        private readonly ?string $preset = null,
    ) {}

    /**
     * Build the map from a connection's "routes" value: a preset name, or an array of
     * "Operation" => "METHOD /Path/:Param" with an optional "extends" preset.
     *
     * @param  string|array<string, mixed>|null  $config
     */
    public static function fromConfig(string|array|null $config): self
    {
        if ($config === null || $config === '') {
            $config = RoutePresets::GENERIC_TICKET_CONNECTOR;
        }

        if (is_string($config)) {
            return new self(self::parseAll(RoutePresets::get($config)), $config);
        }

        $preset = null;
        $definitions = [];

        if (array_key_exists('extends', $config)) {
            $preset = (string) $config['extends'];
            $definitions = RoutePresets::get($preset);
            unset($config['extends']);
        }

        foreach ($config as $operation => $definition) {
            if (! is_string($operation) || ! is_string($definition)) {
                throw new ZnunyConfigurationException(
                    'Znuny routes must map operation names to definitions like "GET /Ticket/:TicketID".'
                );
            }

            $definitions[$operation] = $definition;
        }

        return new self(self::parseAll($definitions), $preset);
    }

    /**
     * The route for an operation; unmapped operations are sent to "POST /<Operation>".
     */
    public function route(string $operation): Route
    {
        return $this->routes[$operation] ?? new Route('POST', '/'.$operation);
    }

    public function has(string $operation): bool
    {
        return isset($this->routes[$operation]);
    }

    /** @return array<string, Route> */
    public function all(): array
    {
        return $this->routes;
    }

    public function preset(): ?string
    {
        return $this->preset;
    }

    /**
     * @param  array<string, string>  $definitions
     * @return array<string, Route>
     */
    private static function parseAll(array $definitions): array
    {
        return array_map(fn (string $definition): Route => Route::parse($definition), $definitions);
    }
}
```

```php
namespace ItsJustVita\LaravelZnuny\Config;

use ItsJustVita\LaravelZnuny\Exceptions\ZnunyConfigurationException;
use ItsJustVita\LaravelZnuny\Routing\RouteMap;

final readonly class ConnectionConfig
{
    public const AUTH_SESSION = 'session';

    public const AUTH_CREDENTIALS = 'credentials';

    public const USER_AGENT = 'agent';

    public const USER_CUSTOMER = 'customer';

    public const TRANSPORT_AUTO = 'auto';

    public const TRANSPORT_PAYLOAD = 'payload';

    public const TRANSPORT_HEADERS = 'headers';

    public function __construct(
        public string $name,
        public string $baseUrl,
        public string $username,
        public string $password,
        public RouteMap $routes,
        public string $auth,
        public string $userType,
        public string $authTransport,
        public bool $verifySsl,
        public int $timeout,
        public int $connectTimeout,
        public int $retries,
        public int $retryDelay,
        public int $batchSize,
    ) {}

    /**
     * @param  array<string, mixed>  $config  one entry of znuny.connections (or a runtime config)
     * @param  array<string, mixed>  $http  the global znuny.http config used as fallback
     */
    public static function fromArray(string $name, array $config, array $http = []): self
    {
        $required = [
            'base_url' => trim((string) ($config['base_url'] ?? '')),
            'username' => (string) ($config['username'] ?? ''),
            'password' => (string) ($config['password'] ?? ''),
        ];

        foreach ($required as $key => $value) {
            if ($value === '') {
                throw new ZnunyConfigurationException("Znuny connection [{$name}] is missing [{$key}].");
            }
        }

        return new self(
            name: $name,
            baseUrl: rtrim($required['base_url'], '/'),
            username: $required['username'],
            password: $required['password'],
            routes: RouteMap::fromConfig($config['routes'] ?? null),
            auth: self::oneOf($name, 'auth', $config['auth'] ?? null, [self::AUTH_SESSION, self::AUTH_CREDENTIALS]),
            userType: self::oneOf($name, 'user_type', $config['user_type'] ?? null, [self::USER_AGENT, self::USER_CUSTOMER]),
            authTransport: self::oneOf($name, 'auth_transport', $config['auth_transport'] ?? null, [self::TRANSPORT_AUTO, self::TRANSPORT_PAYLOAD, self::TRANSPORT_HEADERS]),
            verifySsl: filter_var($config['verify_ssl'] ?? true, FILTER_VALIDATE_BOOL),
            timeout: (int) ($config['timeout'] ?? 30),
            connectTimeout: (int) ($config['connect_timeout'] ?? 3),
            retries: max(0, (int) ($config['retries'] ?? $http['retries'] ?? 3)),
            retryDelay: max(10, (int) ($config['retry_delay'] ?? $http['retry_delay'] ?? 100)),
            batchSize: max(1, (int) ($config['batch_size'] ?? $http['batch_size'] ?? 50)),
        );
    }

    public function usesSession(): bool
    {
        return $this->auth === self::AUTH_SESSION;
    }

    /**
     * The request field Znuny expects for the login of this user type.
     */
    public function loginKey(): string
    {
        return $this->userType === self::USER_CUSTOMER ? 'CustomerUserLogin' : 'UserLogin';
    }

    /**
     * @param  list<string>  $allowed  the first entry is the default
     */
    private static function oneOf(string $connection, string $key, mixed $value, array $allowed): string
    {
        $value = strtolower(trim((string) ($value ?? $allowed[0])));

        if (! in_array($value, $allowed, true)) {
            throw new ZnunyConfigurationException(sprintf(
                'Znuny connection [%s] has invalid [%s] value [%s]. Allowed: %s.',
                $connection,
                $key,
                $value,
                implode(', ', $allowed),
            ));
        }

        return $value;
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\Http;

use ItsJustVita\LaravelZnuny\Exceptions\ZnunyConfigurationException;

final class QueryString
{
    /**
     * Encode parameters the way Znuny's REST transport parses query strings:
     * raw URL encoding, repeated keys for lists, no bracket notation.
     *
     * @param  array<array-key, mixed>  $params
     */
    public static function build(array $params, string $operation = ''): string
    {
        $pairs = [];

        foreach ($params as $key => $value) {
            if ($value === null) {
                continue;
            }

            if (! is_array($value)) {
                $pairs[] = self::pair((string) $key, $value);

                continue;
            }

            if (! array_is_list($value)) {
                throw self::nested($operation, (string) $key);
            }

            foreach ($value as $item) {
                if (is_array($item)) {
                    throw self::nested($operation, (string) $key);
                }

                if ($item !== null) {
                    $pairs[] = self::pair((string) $key, $item);
                }
            }
        }

        return implode('&', $pairs);
    }

    public static function scalar(mixed $value): string
    {
        return is_bool($value) ? ($value ? '1' : '0') : (string) $value;
    }

    private static function pair(string $key, mixed $value): string
    {
        return rawurlencode($key).'='.rawurlencode(self::scalar($value));
    }

    private static function nested(string $operation, string $key): ZnunyConfigurationException
    {
        return new ZnunyConfigurationException(sprintf(
            'Operation [%1$s] uses a GET route, but parameter [%2$s] is a nested structure that Znuny cannot read from a query string. '
            ."Map the operation to a route with a request body, e.g. routes['%1\$s'] = 'POST /%1\$s'.",
            $operation,
            $key,
        ));
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\Http;

use ItsJustVita\LaravelZnuny\Config\ConnectionConfig;
use ItsJustVita\LaravelZnuny\Exceptions\ZnunyConfigurationException;
use ItsJustVita\LaravelZnuny\Routing\Route;

final class RequestBuilder
{
    /** @var array<string, string> */
    public const AUTH_HEADERS = [
        'SessionID' => 'X-OTRS-Header-SessionID',
        'UserLogin' => 'X-OTRS-Header-UserLogin',
        'CustomerUserLogin' => 'X-OTRS-Header-CustomerUserLogin',
        'Password' => 'X-OTRS-Header-Password',
    ];

    public function __construct(
        private readonly ConnectionConfig $config,
    ) {}

    /**
     * @param  array<string, mixed>  $payload  operation data
     * @param  array<string, string>  $auth  SessionID, or the login key and Password
     */
    public function build(string $operation, array $payload, array $auth = []): PreparedRequest
    {
        $route = $this->config->routes->route($operation);
        [$path, $used] = $this->expandPath($route, $operation, $payload);
        $url = $this->config->baseUrl.$path;
        $headers = [];

        if ($auth !== [] && $this->authInHeaders($route)) {
            foreach ($auth as $key => $value) {
                $headers[self::AUTH_HEADERS[$key] ?? 'X-OTRS-Header-'.$key] = $value;
            }

            $auth = [];
        }

        if (! $route->sendsBody()) {
            $query = QueryString::build(array_merge($auth, array_diff_key($payload, array_flip($used))), $operation);

            return new PreparedRequest('GET', $query === '' ? $url : $url.'?'.$query, $path, null, $headers);
        }

        return new PreparedRequest($route->method, $url, $path, array_merge($auth, $payload), $headers);
    }

    private function authInHeaders(Route $route): bool
    {
        return match ($this->config->authTransport) {
            ConnectionConfig::TRANSPORT_HEADERS => true,
            ConnectionConfig::TRANSPORT_PAYLOAD => false,
            default => ! $route->sendsBody(),
        };
    }

    /**
     * Fill ":Param" placeholders from the payload. Lists are joined with commas,
     * which Znuny accepts for TicketGet/TicketHistoryGet batches.
     *
     * @param  array<string, mixed>  $payload
     * @return array{0: string, 1: list<string>}
     */
    private function expandPath(Route $route, string $operation, array $payload): array
    {
        $used = [];

        $path = preg_replace_callback('#:([^/]+)#', function (array $match) use ($route, $operation, $payload, &$used): string {
            $name = $match[1];
            $value = $payload[$name] ?? null;
            $values = array_filter(
                is_array($value) ? array_values($value) : [$value],
                fn (mixed $item): bool => is_scalar($item) && $item !== '',
            );

            if ($values === []) {
                throw new ZnunyConfigurationException(sprintf(
                    'Route [%s] for operation [%s] requires parameter [%s].',
                    $route,
                    $operation,
                    $name,
                ));
            }

            $used[] = $name;

            return implode(',', array_map(fn (mixed $item): string => rawurlencode(QueryString::scalar($item)), $values));
        }, $route->path);

        return [(string) $path, $used];
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\Exceptions;

use Throwable;

class ExceptionMapper
{
    private const VALIDATION_SUFFIXES = ['MissingParameter', 'InvalidParameter', 'WrongStructure', 'EmptyRequest'];

    private const NOT_FOUND_SUFFIXES = ['NotValidTicketID', 'NotTicketData'];

    /**
     * Map a body that contains Znuny's {"Error": {"ErrorCode", "ErrorMessage"}} structure.
     */
    public function fromErrorResponse(
        array $body,
        string $operation,
        string $connection,
        array $payload,
        bool $sessionAuth = true,
        ?int $httpStatus = null,
    ): ZnunyException {
        [$code, $message] = $this->errorParts($body);

        $fullMessage = match (true) {
            $message !== '' => "[{$code}] {$message}",
            $code !== '' => $code,
            default => 'Unknown Znuny error',
        };

        $exception = $this->forErrorCode($code, $message, $operation, $sessionAuth, $fullMessage)
            ?? ($httpStatus !== null && $httpStatus >= 400
                ? $this->forStatus($httpStatus, sprintf('[HTTP %d] %s', $httpStatus, $fullMessage))
                : new GenericZnunyException($fullMessage));

        return $this->decorate($exception, $operation, $connection, $payload, $body, $code, $httpStatus);
    }

    /**
     * Map an HTTP error status whose JSON body has no "Error" structure.
     */
    public function fromHttpStatus(int $status, array $body, string $operation, string $connection, array $payload): ZnunyException
    {
        [$code, $message] = $this->errorParts($body);
        $detail = $message !== '' ? $message : (string) ($body['faultstring'] ?? $body['message'] ?? "{$operation} failed");

        return $this->decorate(
            $this->forStatus($status, sprintf('[HTTP %d] %s', $status, $detail)),
            $operation,
            $connection,
            $payload,
            $body,
            $code,
            $status,
        );
    }

    /**
     * Map any unsuccessful response: Znuny error bodies, HTTP errors, missing routes and non-JSON bodies.
     *
     * @param  array<array-key, mixed>|null  $json  the decoded body, null when it is not JSON
     */
    public function fromResponse(
        int $status,
        ?array $json,
        string $rawBody,
        string $operation,
        string $connection,
        array $payload,
        bool $sessionAuth,
        string $method,
        string $path,
    ): ZnunyException {
        if ($json !== null && isset($json['Error'])) {
            return $this->fromErrorResponse($json, $operation, $connection, $payload, $sessionAuth, $status);
        }

        if ($status === 404 || str_contains($rawBody, 'determine Operation')) {
            $exception = new ZnunyRouteNotFoundException(sprintf(
                'Znuny has no route for %s %s (operation [%s], connection [%s]). '
                .'Check the "routes" configuration of the connection (php artisan znuny:routes %s).',
                $method,
                $path,
                $operation,
                $connection,
                $connection,
            ));

            return $this->decorate($exception, $operation, $connection, $payload, $json ?? $this->raw($rawBody), '', $status);
        }

        if ($status >= 400) {
            if ($json !== null) {
                return $this->fromHttpStatus($status, $json, $operation, $connection, $payload);
            }

            $detail = $this->excerpt($rawBody);

            return $this->decorate(
                $this->forStatus($status, sprintf('[HTTP %d] %s', $status, $detail !== '' ? $detail : "{$operation} failed")),
                $operation,
                $connection,
                $payload,
                $this->raw($rawBody),
                '',
                $status,
            );
        }

        $exception = new ZnunyServerException(sprintf(
            'Znuny returned an unexpected non-JSON response for %s %s (operation [%s]).',
            $method,
            $path,
            $operation,
        ));

        return $this->decorate($exception, $operation, $connection, $payload, $this->raw($rawBody), '', $status);
    }

    public function fromTransportError(Throwable $previous, string $operation, string $connection, array $payload): ZnunyConnectionException
    {
        $exception = new ZnunyConnectionException($previous->getMessage(), 0, $previous);
        $exception->setOperation($operation);
        $exception->setConnection($connection);
        $exception->setRequestPayload($payload);

        return $exception;
    }

    private function forErrorCode(string $code, string $message, string $operation, bool $sessionAuth, string $fullMessage): ?ZnunyException
    {
        $suffix = str_contains($code, '.') ? substr($code, strrpos($code, '.') + 1) : $code;
        $haystack = strtolower($code.' '.$message);
        $lowerMessage = strtolower($message);

        // AuthFail on any operation other than SessionCreate means the cached session expired.
        // Without sessions (credentials mode) and for SessionCreate it means wrong credentials.
        if ($suffix === 'AuthFail' || str_contains($haystack, 'authfail')) {
            return $sessionAuth && $operation !== 'SessionCreate'
                ? new ZnunySessionExpiredException($fullMessage)
                : new ZnunyAuthenticationException($fullMessage);
        }

        if ($sessionAuth && str_contains($lowerMessage, 'session') && (
            str_contains($lowerMessage, 'expired')
            || (str_contains($lowerMessage, 'sessionid') && str_contains($lowerMessage, 'invalid'))
        )) {
            return new ZnunySessionExpiredException($fullMessage);
        }

        if ($suffix === 'AccessDenied') {
            return new ZnunyAccessDeniedException($fullMessage);
        }

        if (in_array($suffix, self::NOT_FOUND_SUFFIXES, true)
            || str_contains($haystack, 'notfound')
            || str_contains($haystack, 'not found')) {
            return $this->notFoundForOperation($operation, $fullMessage);
        }

        if (in_array($suffix, self::VALIDATION_SUFFIXES, true)
            || preg_match('/invalid ?(queue|state|priority|dynamicfield)/', $haystack) === 1) {
            return $this->validation($haystack, $fullMessage);
        }

        if (str_contains($haystack, 'ratelimit') || str_contains($haystack, 'too many')) {
            return new ZnunyRateLimitException($fullMessage);
        }

        if ($code === 'Webservice.InvalidConfiguration') {
            return new ZnunyServerException($fullMessage);
        }

        return null;
    }

    private function validation(string $haystack, string $message): ZnunyValidationException
    {
        return match (true) {
            preg_match('/ticket->queue|invalid ?queue/', $haystack) === 1 => new InvalidQueueException($message),
            preg_match('/ticket->state|invalid ?state/', $haystack) === 1 => new InvalidStateException($message),
            preg_match('/ticket->priority|invalid ?priority/', $haystack) === 1 => new InvalidPriorityException($message),
            str_contains($haystack, 'dynamicfield') => new InvalidDynamicFieldException($message),
            default => new ZnunyValidationException($message),
        };
    }

    private function notFoundForOperation(string $operation, string $message): ZnunyNotFoundException
    {
        return match (true) {
            str_starts_with($operation, 'Ticket') => new TicketNotFoundException($message),
            str_starts_with($operation, 'Queue') => new QueueNotFoundException($message),
            str_starts_with($operation, 'Customer') => new CustomerNotFoundException($message),
            default => new ZnunyNotFoundException($message),
        };
    }

    private function forStatus(int $status, string $message): ZnunyException
    {
        return match (true) {
            $status === 401, $status === 403 => new ZnunyAuthenticationException($message),
            $status === 429 => new ZnunyRateLimitException($message),
            $status >= 500 => new ZnunyServerException($message),
            default => new GenericZnunyException($message),
        };
    }

    /** @return array{0: string, 1: string} */
    private function errorParts(array $body): array
    {
        $error = is_array($body['Error'] ?? null) ? $body['Error'] : [];

        return [(string) ($error['ErrorCode'] ?? ''), (string) ($error['ErrorMessage'] ?? '')];
    }

    private function decorate(
        ZnunyException $exception,
        string $operation,
        string $connection,
        array $payload,
        array $body,
        string $code,
        ?int $status,
    ): ZnunyException {
        return $exception
            ->setErrorCode($code)
            ->setOperation($operation)
            ->setConnection($connection)
            ->setRequestPayload($payload)
            ->setResponseBody($body)
            ->setHttpStatus($status);
    }

    /** @return array{raw: string} */
    private function raw(string $body): array
    {
        return ['raw' => mb_substr($body, 0, 1000)];
    }

    private function excerpt(string $body): string
    {
        return trim(mb_substr(trim($body), 0, 500));
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny;

use Illuminate\Http\Client\ConnectionException;
use Illuminate\Http\Client\PendingRequest;
use Illuminate\Http\Client\RequestException;
use Illuminate\Http\Client\Response;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;
use ItsJustVita\LaravelZnuny\Config\ConnectionConfig;
use ItsJustVita\LaravelZnuny\Events\ZnunyRequestFailed;
use ItsJustVita\LaravelZnuny\Events\ZnunyRequestSent;
use ItsJustVita\LaravelZnuny\Events\ZnunyResponseReceived;
use ItsJustVita\LaravelZnuny\Events\ZnunySessionRefreshed;
use ItsJustVita\LaravelZnuny\Exceptions\ExceptionMapper;
use ItsJustVita\LaravelZnuny\Exceptions\ZnunyConfigurationException;
use ItsJustVita\LaravelZnuny\Exceptions\ZnunyException;
use ItsJustVita\LaravelZnuny\Exceptions\ZnunySessionExpiredException;
use ItsJustVita\LaravelZnuny\Http\PreparedRequest;
use ItsJustVita\LaravelZnuny\Http\RequestBuilder;
use ItsJustVita\LaravelZnuny\Routing\RouteMap;
use ItsJustVita\LaravelZnuny\Session\SessionManager;
use ItsJustVita\LaravelZnuny\Support\Redactor;
use stdClass;
use Throwable;

class ZnunyClient
{
    protected readonly ConnectionConfig $settings;

    protected readonly RequestBuilder $requests;

    /**
     * @param  array<string, mixed>  $config  connection config, see config/znuny.php
     */
    public function __construct(
        protected readonly string $connection,
        array $config,
        protected readonly SessionManager $sessionManager,
        protected readonly ExceptionMapper $exceptionMapper = new ExceptionMapper,
    ) {
        $this->settings = ConnectionConfig::fromArray($connection, $config, (array) config('znuny.http', []));
        $this->requests = new RequestBuilder($this->settings);
    }

    public function connection(): string
    {
        return $this->connection;
    }

    public function settings(): ConnectionConfig
    {
        return $this->settings;
    }

    public function routes(): RouteMap
    {
        return $this->settings->routes;
    }

    /**
     * Call any Znuny operation with routing, authentication, error mapping, events and logging.
     *
     * @param  array<string, mixed>  $payload
     * @return array<array-key, mixed>
     */
    public function call(string $operation, array $payload = []): array
    {
        if (! $this->settings->usesSession()) {
            return $this->send($operation, $payload, $this->credentials());
        }

        try {
            return $this->send($operation, $payload, ['SessionID' => $this->sessionId()]);
        } catch (ZnunySessionExpiredException $e) {
            if (! config('znuny.session.auto_retry_on_expired', true)) {
                throw $e;
            }

            $this->sessionManager->invalidate($this->connection);
            $sessionId = $this->sessionId();

            event(new ZnunySessionRefreshed(connection: $this->connection));

            return $this->send($operation, $payload, ['SessionID' => $sessionId]);
        }
    }

    /**
     * @deprecated since 0.2.0, use call()
     *
     * @param  array<string, mixed>  $payload
     * @return array<array-key, mixed>
     */
    public function request(string $operation, array $payload = []): array
    {
        return $this->call($operation, $payload);
    }

    /**
     * Check the credentials: a fresh SessionCreate in session mode, a minimal
     * TicketSearch in credentials mode.
     */
    public function ping(): bool
    {
        if ($this->settings->usesSession()) {
            $this->createSession();
        } else {
            $this->call('TicketSearch', ['Limit' => 1]);
        }

        return true;
    }

    protected function sessionId(): string
    {
        return $this->sessionManager->sessionId($this->connection, fn (): string => $this->createSession());
    }

    protected function createSession(): string
    {
        $response = $this->send('SessionCreate', [], $this->credentials());
        $sessionId = (string) ($response['SessionID'] ?? '');

        if ($sessionId === '') {
            throw $this->exceptionMapper->fromErrorResponse(
                body: $response,
                operation: 'SessionCreate',
                connection: $this->connection,
                payload: $this->credentials(),
                sessionAuth: false,
            );
        }

        return $sessionId;
    }

    /** @return array<string, string> */
    protected function credentials(): array
    {
        return [
            $this->settings->loginKey() => $this->settings->username,
            'Password' => $this->settings->password,
        ];
    }

    /**
     * @param  array<string, mixed>  $payload
     * @param  array<string, string>  $auth
     * @return array<array-key, mixed>
     */
    protected function send(string $operation, array $payload, array $auth): array
    {
        try {
            $request = $this->requests->build($operation, $payload, $auth);
        } catch (ZnunyConfigurationException $e) {
            throw $e->setOperation($operation)->setConnection($this->connection);
        }

        $data = array_merge($auth, $payload);
        $redacted = Redactor::redact($data);

        event(new ZnunyRequestSent(
            connection: $this->connection,
            operation: $operation,
            payload: $redacted,
            method: $request->method,
            path: $request->path,
        ));

        $this->log('info', 'log_requests', 'Znuny request', [
            'connection' => $this->connection,
            'operation' => $operation,
            'method' => $request->method,
            'path' => $request->path,
            'payload' => Redactor::forLog($data),
        ]);

        $start = microtime(true);

        try {
            $response = $this->dispatch($request);
        } catch (ConnectionException $e) {
            throw $this->failed($operation, $request, $redacted, $this->exceptionMapper->fromTransportError(
                $e,
                $operation,
                $this->connection,
                $data,
            ));
        }

        $elapsed = (microtime(true) - $start) * 1000.0;
        $json = $this->decode($response);

        if ($json === null || $response->failed() || isset($json['Error'])) {
            throw $this->failed($operation, $request, $redacted, $this->exceptionMapper->fromResponse(
                status: $response->status(),
                json: $json,
                rawBody: $response->body(),
                operation: $operation,
                connection: $this->connection,
                payload: $data,
                sessionAuth: $this->settings->usesSession(),
                method: $request->method,
                path: $request->path,
            ));
        }

        event(new ZnunyResponseReceived(
            connection: $this->connection,
            operation: $operation,
            responseTimeMs: $elapsed,
            payload: $redacted,
            response: $json,
            status: $response->status(),
        ));

        $this->log('debug', 'log_responses', 'Znuny response', [
            'connection' => $this->connection,
            'operation' => $operation,
            'status' => $response->status(),
            'duration_ms' => round($elapsed, 1),
            'response' => Redactor::forLog($json),
        ]);

        return $json;
    }

    protected function dispatch(PreparedRequest $request): Response
    {
        $client = $this->httpClient()->withHeaders($request->headers);

        if ($request->body === null) {
            return $client->send('GET', $request->url);
        }

        $body = json_encode(
            $request->body === [] ? new stdClass : $request->body,
            JSON_THROW_ON_ERROR | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE,
        );

        return $client->withBody($body, 'application/json')->send($request->method, $request->url);
    }

    /** @return array<array-key, mixed>|null */
    protected function decode(Response $response): ?array
    {
        $decoded = json_decode($response->body(), true);

        return is_array($decoded) ? $decoded : null;
    }

    /**
     * Dispatch the failure event, write the error log and hand the exception back for throwing.
     */
    protected function failed(string $operation, PreparedRequest $request, array $redacted, ZnunyException $exception): ZnunyException
    {
        event(new ZnunyRequestFailed(
            connection: $this->connection,
            operation: $operation,
            exception: $exception,
            payload: $redacted,
        ));

        $this->log('error', 'log_errors', 'Znuny error', [
            'connection' => $this->connection,
            'operation' => $operation,
            'method' => $request->method,
            'path' => $request->path,
            'http_status' => $exception->getHttpStatus(),
            'code' => $exception->getErrorCode(),
            'message' => $exception->getMessage(),
        ]);

        return $exception;
    }

    protected function log(string $level, string $toggle, string $message, array $context): void
    {
        if (! config('znuny.logging.enabled') || ! config("znuny.logging.{$toggle}")) {
            return;
        }

        Log::channel((string) config('znuny.logging.channel', 'znuny'))->{$level}($message, $context);
    }

    protected function httpClient(): PendingRequest
    {
        $client = Http::timeout($this->settings->timeout)
            ->connectTimeout($this->settings->connectTimeout);

        if ($this->settings->retries > 0) {
            $delays = array_map(
                fn (int $attempt): int => $this->settings->retryDelay * (2 ** $attempt),
                range(0, $this->settings->retries - 1),
            );

            $client = $client->retry($delays, throw: false, when: function (Throwable $exception): bool {
                if ($exception instanceof ConnectionException) {
                    return true;
                }

                // A missing route is a configuration problem that no retry can fix.
                return $exception instanceof RequestException
                    && $exception->response->serverError()
                    && ! str_contains($exception->response->body(), 'determine Operation');
            });
        }

        return $this->settings->verifySsl ? $client : $client->withOptions(['verify' => false]);
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\Data;

use InvalidArgumentException;
use ItsJustVita\LaravelZnuny\Data\Concerns\HasAttributes;

final readonly class Attachment
{
    use HasAttributes;

    /**
     * @param  string  $content  decoded file contents
     * @param  array<string, mixed>  $attributes  raw Znuny fields without the base64 content
     */
    public function __construct(
        public string $filename,
        public string $contentType,
        public string $content,
        public int $filesize,
        public ?string $contentId = null,
        public ?string $disposition = null,
        public array $attributes = [],
    ) {}

    public static function fromContent(string $filename, string $content, string $contentType = 'application/octet-stream'): self
    {
        return new self(
            filename: $filename,
            contentType: $contentType,
            content: $content,
            filesize: strlen($content),
        );
    }

    public static function fromPath(string $path, ?string $filename = null, ?string $contentType = null): self
    {
        if (! is_file($path) || ! is_readable($path)) {
            throw new InvalidArgumentException("Attachment file [{$path}] does not exist or is not readable.");
        }

        $detected = function_exists('mime_content_type') ? mime_content_type($path) : false;

        return self::fromContent(
            filename: $filename ?? basename($path),
            content: (string) file_get_contents($path),
            contentType: $contentType ?? ($detected ?: 'application/octet-stream'),
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\DynamicFields;

use ItsJustVita\LaravelZnuny\Exceptions\InvalidDynamicFieldException;

class DynamicFieldValidator
{
    /** @var array<string, FieldDefinition> */
    private array $definitions;

    /**
     * @param  array<string, array<string, mixed>>  $definitions  raw config entries
     */
    public function __construct(array $definitions)
    {
        $parsed = [];

        foreach ($definitions as $name => $spec) {
            $parsed[$name] = FieldDefinition::fromArray($name, (array) $spec);
        }

        $this->definitions = $parsed;
    }

    public static function fromConfig(): self
    {
        return new self((array) config('znuny.dynamic_fields', []));
    }

    /**
     * @param  array<string, mixed>  $fields  name => value
     */
    public function validate(array $fields): void
    {
        foreach ($fields as $name => $value) {
            $definition = $this->definitions[$name] ?? null;

            if ($definition !== null) {
                $this->validateOne($definition, $value);
            }
        }
    }

    private function validateOne(FieldDefinition $def, mixed $value): void
    {
        switch ($def->type) {
            case 'string':
                if (! is_string($value)) {
                    throw $this->invalid($def, 'expected string, got '.gettype($value));
                }
                $this->assertAllowed($def, [$value]);

                return;

            case 'integer':
                if (! is_int($value)) {
                    throw $this->invalid($def, 'expected integer, got '.gettype($value));
                }
                $this->assertRange($def, $value);

                return;

            case 'float':
                if (! is_int($value) && ! is_float($value)) {
                    throw $this->invalid($def, 'expected float, got '.gettype($value));
                }
                $this->assertRange($def, $value);

                return;

            case 'boolean':
                if (! is_bool($value)) {
                    throw $this->invalid($def, 'expected boolean, got '.gettype($value));
                }

                return;

            case 'array':
                if (! is_array($value) || ! array_is_list($value)) {
                    throw $this->invalid($def, 'expected list, got '.gettype($value));
                }
                $this->assertAllowed($def, $value);

                return;

            default:
                throw $this->invalid($def, "unsupported field type '{$def->type}'");
        }
    }

    /**
     * @param  array<int, mixed>  $values
     */
    private function assertAllowed(FieldDefinition $def, array $values): void
    {
        if ($def->allowed === null) {
            return;
        }

        foreach ($values as $value) {
            if (! in_array($value, $def->allowed, true)) {
                $shown = is_scalar($value) ? (string) $value : gettype($value);

                throw $this->invalid($def, "value '{$shown}' not in allowed set [".implode(', ', $def->allowed).']');
            }
        }
    }

    private function assertRange(FieldDefinition $def, int|float $value): void
    {
        if ($def->min !== null && $value < $def->min) {
            throw $this->invalid($def, "value {$value} is below minimum {$def->min}");
        }

        if ($def->max !== null && $value > $def->max) {
            throw $this->invalid($def, "value {$value} is above maximum {$def->max}");
        }
    }

    private function invalid(FieldDefinition $def, string $message): InvalidDynamicFieldException
    {
        return new InvalidDynamicFieldException("DynamicField [{$def->name}]: {$message}");
    }
}
```

```php
     * @return Collection<int, Ticket>
     */
    public function findMany(array $ticketIds, bool $withArticles = false, bool $withDynamicFields = false, bool $withAttachments = false): Collection
    {
        $ids = array_values(array_unique(array_map('strval', $ticketIds)));
        $options = self::fetchOptions($withArticles, $withDynamicFields, $withAttachments);
        $found = [];

        foreach (array_chunk($ids, $this->client->settings()->batchSize) as $chunk) {
            foreach ($this->fetchChunk($chunk, $options) as $ticket) {
                $found[$ticket->id] = $ticket;
            }
        }

        return collect($ids)
            ->filter(fn (string $id): bool => isset($found[$id]))
            ->map(fn (string $id): Ticket => $found[$id])
            ->values();
    }

    /**
     * @param  array<string, mixed>  $ticket  ticket attributes (camelCase or Znuny keys)
     * @param  array<string, mixed>  $dynamicFields  name => value
     */
    public function update(string $ticketId, array $ticket = [], array $dynamicFields = []): void
    {
        if ($ticket === [] && $dynamicFields === []) {
            throw new InvalidArgumentException('Nothing to update: pass ticket attributes and/or dynamic fields.');
        }

        $payload = ['TicketID' => $ticketId];

        if ($ticket !== []) {
            $payload['Ticket'] = TicketInputMapper::mapTicket($ticket);
        }

        if ($dynamicFields !== []) {
            DynamicFieldValidator::fromConfig()->validate($dynamicFields);
            $payload['DynamicField'] = TicketInputMapper::mapDynamicFields($dynamicFields);
        }

        $this->client->call('TicketUpdate', $payload);

        event(new ZnunyTicketUpdated(
            connection: $this->client->connection(),
            ticketId: $ticketId,
            changes: $ticket,
            dynamicFields: $dynamicFields,
        ));
    }

    /**
     * @param  array<string, mixed>  $article
     * @param  list<Attachment>  $attachments
     * @return string|null the ArticleID of the new article
     */
    public function addArticle(string $ticketId, array $article, array $attachments = []): ?string
    {
        $payload = [
            'TicketID' => $ticketId,
            'Article' => TicketInputMapper::mapArticle($article),
        ];

        if ($attachments !== []) {
            $payload['Attachment'] = TicketInputMapper::mapAttachments($attachments);
        }

        $response = $this->client->call('TicketUpdate', $payload);
        $articleId = (string) ($response['ArticleID'] ?? '');
        $articleId = $articleId !== '' ? $articleId : null;

        event(new ZnunyArticleAdded(
            connection: $this->client->connection(),
            ticketId: $ticketId,
            article: $article,
            articleId: $articleId,
        ));

        return $articleId;
    }

    public function close(string $ticketId, string $state = 'closed successful'): void
    {
        $this->update($ticketId, ['state' => $state]);
    }

    /**
     * @return Collection<int, HistoryEntry>
     */
    public function history(string $ticketId): Collection
    {
        $entries = $this->client->call('TicketHistoryGet', ['TicketID' => $ticketId])['TicketHistory'][0]['History'] ?? [];

        return collect(is_array($entries) ? $entries : [])
            ->filter(fn (mixed $entry): bool => is_array($entry))
            ->map(fn (array $entry): HistoryEntry => HistoryEntry::fromZnunyResponse($entry))
            ->values();
    }

    public function query(): TicketBuilder
    {
        return new TicketBuilder($this->client, $this);
    }

    public function where(string $field, mixed $value): TicketBuilder
    {
        return $this->query()->where($field, $value);
    }

    public function whereState(string|array $states): TicketBuilder
    {
        return $this->query()->whereState($states);
    }

    public function whereQueue(string|array $queues): TicketBuilder
    {
        return $this->query()->whereQueue($queues);
    }

    public function whereCustomerId(string $customerId): TicketBuilder
    {
        return $this->query()->whereCustomerId($customerId);
    }

    /**
     * TicketGet flags for the requested related data.
     *
     * @return array<string, int>
     */
    public static function fetchOptions(bool $withArticles, bool $withDynamicFields, bool $withAttachments): array
    {
        $options = [];

        if ($withArticles || $withAttachments) {
            $options['AllArticles'] = 1;
        }

        if ($withAttachments) {
            $options['Attachments'] = 1;
        }

        if ($withDynamicFields) {
            $options['DynamicFields'] = 1;
        }

        return $options;
    }

    /**
     * Znuny rejects a whole batch with AccessDenied when one ticket is missing or not
     * accessible, so a rejected batch is retried ticket by ticket.
     *
     * @param  list<string>  $ids
     * @param  array<string, int>  $options
     * @return list<Ticket>
     */
    protected function fetchChunk(array $ids, array $options): array
    {
        try {
            $rows = $this->client->call('TicketGet', ['TicketID' => $ids] + $options)['Ticket'] ?? [];
        } catch (ZnunyAccessDeniedException|TicketNotFoundException) {
            if (count($ids) === 1) {
                return [];
            }

            return array_merge(...array_map(fn (string $id): array => $this->fetchChunk([$id], $options), $ids));
        }

        $tickets = [];

        foreach (is_array($rows) ? $rows : [] as $row) {
            if (is_array($row) && isset($row['TicketID'])) {
                $tickets[] = Ticket::fromZnunyResponse($row);
            }
        }

        return $tickets;
    }
}
```

```php
    public function orderBy(string $field, string $direction = 'Up'): self
    {
        $this->params['SortBy'] = $field;
        $this->params['OrderBy'] = in_array(strtolower($direction), ['down', 'desc'], true) ? 'Down' : 'Up';

        return $this;
    }

    public function orderByDesc(string $field): self
    {
        return $this->orderBy($field, 'Down');
    }

    public function limit(int $limit): self
    {
        $this->limit = $limit;
        $this->params['Limit'] = $limit;

        return $this;
    }

    /** @return Collection<int, string> */
    public function ids(): Collection
    {
        $ids = $this->client->call('TicketSearch', $this->params)['TicketID'] ?? [];

        return collect(array_map('strval', (array) $ids))->values();
    }

    /** @return Collection<int, Ticket> */
    public function get(): Collection
    {
        $ids = $this->ids();

        return $ids->isEmpty() ? collect() : $this->fetch($ids->all());
    }

    /**
     * Fetches all matching IDs, then loads only the tickets of the requested page.
     */
    public function paginate(int $perPage = 25, int $page = 1): LengthAwarePaginator
    {
        $ids = $this->ids();
        $total = $ids->count();

        if ($total === 0) {
            return new LengthAwarePaginator([], 0, $perPage, $page);
        }

        $pageIds = $ids->slice(($page - 1) * $perPage, $perPage)->values()->all();

        return new LengthAwarePaginator(
            items: $this->fetch($pageIds)->all(),
            total: $total,
            perPage: $perPage,
            currentPage: $page,
        );
    }

    /** @return Generator<int, Ticket> */
    public function lazy(int $chunkSize = 100): Generator
    {
        foreach (array_chunk($this->ids()->all(), max(1, $chunkSize)) as $chunk) {
            foreach ($this->fetch($chunk) as $ticket) {
                yield $ticket;
            }
        }
    }

    /**
     * @param  array<int, string>  $ids
     * @return Collection<int, Ticket>
     */
    protected function fetch(array $ids): Collection
    {
        return $this->resource->findMany($ids, $this->withArticles, $this->withDynamicFields, $this->withAttachments);
    }
```

```php
namespace ItsJustVita\LaravelZnuny\Webhooks;

/**
 * Reads event name and IDs from webhook payloads. Tolerant because Znuny admins can
 * reshape the payload with mappings.
 */
final class WebhookPayload
{
    public static function event(array $payload, ?string $routeEvent): string
    {
        if ($routeEvent !== null && $routeEvent !== '') {
            return $routeEvent;
        }

        $event = $payload['Event'] ?? null;

        if (is_array($event) && is_string($event['Event'] ?? null) && $event['Event'] !== '') {
            return $event['Event'];
        }

        return is_string($event) && $event !== '' ? $event : 'unknown';
    }

    public static function ticketId(array $payload): ?string
    {
        return self::id($payload['Event']['TicketID'] ?? null) ?? self::id($payload['Ticket']['TicketID'] ?? null);
    }

    public static function articleId(array $payload): ?string
    {
        return self::id($payload['Event']['ArticleID'] ?? null) ?? self::id($payload['Article']['ArticleID'] ?? null);
    }

    private static function id(mixed $value): ?string
    {
        return is_scalar($value) && (string) $value !== '' ? (string) $value : null;
    }
}
```

```php
<?php

namespace ItsJustVita\LaravelZnuny\Webhooks;

use Closure;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Log;
use Symfony\Component\HttpFoundation\Response;

/**
 * Authenticates requests from a Znuny requester (middleware alias "znuny.webhook").
 * Fails closed: without a configured secret every request is rejected.
 */
class AuthenticateWebhook
{
    public function handle(Request $request, Closure $next): Response
    {
        $config = (array) config('znuny.webhooks.auth', []);
        $type = strtolower((string) ($config['type'] ?? 'token'));

        $authorized = match ($type) {
            'none' => true,
            'token' => $this->validToken($request, $config),
            'basic' => $this->validBasic($request, $config),
            default => $this->reject("unknown auth type [{$type}]"),
        };

        if (! $authorized) {
            return new JsonResponse(['Error' => 'Unauthorized'], 401);
        }

        return $next($request);
    }

    private function validToken(Request $request, array $config): bool
    {
        $expected = (string) ($config['token'] ?? '');

        if ($expected === '') {
            return $this->reject('ZNUNY_WEBHOOK_TOKEN is not set');
        }

        $candidates = [
            (string) $request->bearerToken(),
            (string) $request->header((string) ($config['header'] ?? 'X-Znuny-Token'), ''),
        ];

        foreach ($candidates as $candidate) {
            if ($candidate !== '' && hash_equals($expected, $candidate)) {
                return true;
            }
        }

        return false;
    }

    private function validBasic(Request $request, array $config): bool
    {
        $username = (string) ($config['username'] ?? '');
        $password = (string) ($config['password'] ?? '');

        if ($username === '' || $password === '') {
            return $this->reject('ZNUNY_WEBHOOK_USERNAME / ZNUNY_WEBHOOK_PASSWORD are not set');
        }

        return hash_equals($username, (string) $request->getUser())
            && hash_equals($password, (string) $request->getPassword());
    }

    private function reject(string $reason): bool
    {
        Log::warning("Znuny webhook rejected: {$reason}.");

        return false;
    }
}
```

````markdown
## Setting up the web service in Znuny

1. In Znuny open **Admin → Web Services → Add Web Service → Import web service** and import `GenericTicketConnectorREST.yml`. Znuny ships it in `var/webservices/examples/`; it is also [on GitHub](https://github.com/znuny/Znuny/blob/dev/development/webservices/GenericTicketConnectorREST.yml).
2. Keep the name `GenericTicketConnectorREST` or choose your own. The base URL is `https://<host>/otrs/nph-genericinterface.pl/Webservice/<name>`; use your installation's script alias if it is not `/otrs/`.
3. Create an agent for the API and give it permissions on the queues it needs.

The default route preset matches this web service, so nothing else needs to be configured.

## Configuration

### Connections

```php
// config/znuny.php
'connections' => [
    'default' => [
        'base_url'        => env('ZNUNY_BASE_URL'),
        'username'        => env('ZNUNY_USERNAME'),
        'password'        => env('ZNUNY_PASSWORD'),
        'routes'          => env('ZNUNY_ROUTES', 'generic-ticket-connector'),
        'auth'            => env('ZNUNY_AUTH', 'session'),
        'user_type'       => env('ZNUNY_USER_TYPE', 'agent'),
        'auth_transport'  => env('ZNUNY_AUTH_TRANSPORT', 'auto'),
        'verify_ssl'      => env('ZNUNY_VERIFY_SSL', true),
        'timeout'         => env('ZNUNY_TIMEOUT', 30),
        'connect_timeout' => env('ZNUNY_CONNECT_TIMEOUT', 3),
    ],
],
```

A connection can also set `retries`, `retry_delay` (milliseconds) and `batch_size`; they default to the values under `http`.

### Routes

Znuny maps REST routes to operations per web service. Tell the package which routes yours uses:

| `routes` | Meaning |
|---|---|
| `generic-ticket-connector` (default) | Znuny's stock web service: `POST /Session`, `GET /Session/:SessionID`, `POST /Ticket`, `GET /Ticket/:TicketID`, `GET /Ticket` (search), `PATCH /Ticket/:TicketID`, `GET /TicketHistory/:TicketID` |
| `operation-name` | Routes named after the operations: `POST /<Operation>`, plus `POST /TicketGet/:TicketID`, `POST /TicketUpdate/:TicketID` and `POST /QueueGet/:QueueID` |
| array | Your own mapping in Znuny's notation `"METHOD /Path/:Param"`, optionally starting from a preset with `extends` |

```php
'routes' => [
    'extends'      => 'generic-ticket-connector',
    'TicketSearch' => 'POST /TicketSearch',   // e.g. to search by dynamic fields
    'QueueList'    => 'GET /Queue',
],
```

Operations without a mapping are sent to `POST /<Operation>`. `php artisan znuny:routes` prints the effective routes of a connection.

For `GET` routes the parameters go into the query string the way Znuny parses it (`States=new&States=open`). Nested parameters such as dynamic field search conditions cannot be expressed in a query string; map that operation to a route with a request body (`POST`), as in the example above.

### Authentication

| Key | Values | Default |
|---|---|---|
| `auth` | `session`: log in once via `SessionCreate` and reuse the cached `SessionID`; an expired session is replaced and the request retried once. `credentials`: send login and password with every request. | `session` |
| `user_type` | `agent` (`UserLogin`) or `customer` (`CustomerUserLogin`) | `agent` |
| `auth_transport` | `auto`: `X-OTRS-Header-*` headers for `GET` routes, request data otherwise. `payload`: always in the request data. `headers`: always as headers. | `auto` |

Headers keep session IDs and passwords out of URLs and access logs. They need Znuny 6.5 or newer; on older versions use `payload`.

Input keys are camelCase (`queueId`, `customerUser`, `isVisibleForCustomer`, …). Any other key is passed to Znuny unchanged, so `'HistoryComment' => '…'` works too.

`Ticket`, `Article` and the other DTOs expose typed properties plus every raw field Znuny returned:

```php
$ticket->owner;                                    // typed property

```

## Searching tickets

```php
$tickets = Znuny::tickets()
    ->whereState(['new', 'open'])
    ->whereQueue('Support')
    ->whereCreatedAfter(now()->subDays(30))
    ->whereChangedBefore(now()->subDay())
    ->orderBy('Age', 'desc')
    ->limit(50)
    ->get();                                       // Collection<Ticket>

## Calling any operation

Every other operation — Znuny add-ons such as FAQ or ITSM, or your own — goes through the same routing, authentication, error handling, events and logging:

```php
$result = Znuny::call('FAQSearch', ['Title' => 'VPN*']);

## Lookups (custom operations)

Znuny has no operations for listing queues, states, priorities, types or customer users. If your web service exposes such custom operations, these helpers use them and cache the results (see `cache.ttl`):

| Method | Operation | Expected response |
|---|---|---|
| `Znuny::queues()->all()`, `findByName()` | `QueueList` | `{"Queue": [{"QueueID", "Name", "GroupID", "ValidID", "Comment"}]}` |
| `Znuny::queues()->find($id)` | `QueueGet` (`QueueID`) | `{"Queue": [{...}]}` |

## Webhooks (Znuny to Laravel)

The package can receive Znuny's outgoing events and dispatch them as Laravel events.

1. Enable the endpoint and set a secret:

   ```dotenv
   ZNUNY_WEBHOOKS_ENABLED=true
   ZNUNY_WEBHOOK_TOKEN=a-long-random-string
   ```

   This registers `POST /znuny/webhooks/{event?}` (see `webhooks.route_prefix`) with the `api` middleware group and the `znuny.webhook` authentication middleware.

2. In Znuny create a web service (or extend one) with a **requester**:
   - network transport `HTTP::REST` with the endpoint `https://your-app.example.com/znuny/webhooks`;
   - an invoker of type `Ticket::Generic`, triggered by the events you need (for example `TicketCreate`, `ArticleCreate`, `TicketStateUpdate`);
   - a controller mapping for the invoker, e.g. `POST` to `/TicketCreate` (the last path segment becomes the event name);
   - the additional header `X-Znuny-Token: <your token>` (or `Authorization: Bearer <your token>`). Alternatively use Znuny's BasicAuth together with `ZNUNY_WEBHOOK_AUTH=basic`, `ZNUNY_WEBHOOK_USERNAME` and `ZNUNY_WEBHOOK_PASSWORD`.

3. Listen to the event:

   ```php
   use ItsJustVita\LaravelZnuny\Events\ZnunyWebhookReceived;

   Event::listen(function (ZnunyWebhookReceived $event) {
       if ($event->is('TicketCreate')) {
           $ticket = $event->ticket();   // built from the payload; null if no ticket data was sent
           // $event->ticketId, $event->articleId, $event->payload, $event->parameters
       }
   });
   ```

The endpoint answers `200 {}`; Znuny applies data returned by the endpoint to the ticket, so nothing else is returned. Requests without valid credentials get `401`, and if no secret is configured every request is rejected.

For several Znuny systems, for example one per tenant, register your own route with the middleware:

```php
use ItsJustVita\LaravelZnuny\Webhooks\WebhookController;

Route::post('tenants/{tenant}/znuny', WebhookController::class)->middleware('znuny.webhook');
// $event->parameters === ['tenant' => 'acme']
```

## Events

| Event | Fired when |
|---|---|
| `ZnunyRequestSent` | before every HTTP call (`connection`, `operation`, `method`, `path`, redacted `payload`) |
| `ZnunyResponseReceived` | after a successful response (`responseTimeMs`, `status`, `response`) |
| `ZnunyRequestFailed` | when a call fails (`exception`) |
| `ZnunySessionRefreshed` | after an expired session was replaced |
| `ZnunyTicketCreated` | after `create()->save()` |
| `ZnunyTicketUpdated` | after `update()` (`changes`, `dynamicFields`) |
| `ZnunyArticleAdded` | after `addArticle()` (`article`, `articleId`) |
| `ZnunyWebhookReceived` | when Znuny calls the webhook endpoint |

Passwords, session IDs and tokens are replaced with `[REDACTED]` in event payloads, logs and exceptions.

├── ZnunyValidationException             // *.MissingParameter, *.InvalidParameter, ...
│   ├── InvalidQueueException
│   ├── InvalidStateException
│   ├── InvalidPriorityException
│   └── InvalidDynamicFieldException
├── ZnunyNotFoundException
│   ├── TicketNotFoundException
│   ├── CustomerNotFoundException
│   └── QueueNotFoundException

Every exception carries `getOperation()`, `getErrorCode()`, `getConnection()`, `getHttpStatus()`, the redacted `getRequestPayload()` and `getResponseBody()`.
````

````markdown
# Upgrade guide

## 0.1.x → 0.2.0

0.2.0 makes the package work with any Znuny installation. Most changes are additions, but a few affect existing installations.

### Default routes (high impact)

0.1 sent every request as `POST <base_url>/<Operation>`, with the ID appended for `TicketGet`, `TicketUpdate` and `QueueGet`. 0.2 uses the routes of Znuny's stock `GenericTicketConnectorREST` web service by default.

If your web service uses routes named after the operations, keep the old behaviour per connection:

```php
// config/znuny.php
'connections' => [
    'default' => [
        // ...
        'routes' => 'operation-name',
    ],
],
```

or set `ZNUNY_ROUTES=operation-name`. Runtime connections need it as well:

```php
Znuny::usingCredentials($url, $username, $password, options: ['routes' => 'operation-name']);
Znuny::build(['base_url' => $url, 'username' => $username, 'password' => $password, 'routes' => 'operation-name']);
```

If only some routes differ, extend a preset:

```php
'routes' => [
    'extends'   => 'operation-name',
    'TicketGet' => 'POST /TicketGet',
],
```

Check the result with `php artisan znuny:routes` and `php artisan znuny:test-connection`.

### Authentication on GET routes

`auth_transport` defaults to `auto`: for `GET` routes the session ID or credentials are sent as `X-OTRS-Header-*` headers, which Znuny supports since 6.5. With `operation-name` routes every request is a `POST`, so nothing changes. On Znuny 6.0 or OTRS 6 with `GET` routes set `'auth_transport' => 'payload'`.

### Queue resolution removed

`Znuny::queues()->resolve()` and the `queues` config block (`queues.default`, `queues.resolution`) are gone because they encoded one organisation's business rules. Keep such a mapping in your application, for example:

```php
// config/services.php
'znuny_queues' => [
    'default'    => env('ZNUNY_DEFAULT_QUEUE_ID'),
    'relocation' => ['business' => 901, 'private' => 902],
],

// application code
$queueId = config("services.znuny_queues.relocation.{$segment}") ?? config('services.znuny_queues.default');
```

### Removed and renamed config keys

- `http.pool_size` → replaced by `http.batch_size` (maximum ticket IDs per `TicketGet` request, default 50).
- `cache.ttl.services` → removed (it was never used).
- `queues` → removed (see above).
- New: `connections.*.routes`, `auth`, `user_type`, `auth_transport`, `webhooks.auth`.

Compare your published `config/znuny.php` with the package version (`php artisan vendor:publish --tag=znuny-config --force` overwrites yours).

### `ZnunyClient::request()`

`request()` is now a deprecated alias of `call()` and no longer accepts path suffixes:

```php
// before
$client->request('TicketGet/123', ['TicketID' => '123']);
// after
Znuny::call('TicketGet', ['TicketID' => '123']);
```

### Exceptions

- `*.AccessDenied` errors throw `ZnunyAccessDeniedException` (before: `GenericZnunyException`). Znuny usually reports tickets that do not exist this way.
- HTTP errors without a Znuny error body now throw (`ZnunyRouteNotFoundException`, `ZnunyAuthenticationException`, `ZnunyServerException`, …) instead of returning an empty array. A `2xx` response that is not JSON throws `ZnunyServerException`.
- HTTP 4xx responses other than 401, 403, 404 and 429 throw `GenericZnunyException` (before: `ZnunyServerException`).
- `TicketCreate` without a `TicketID` in the response throws `ZnunyServerException` (before: `InvalidArgumentException`).
- Configuration problems throw `ZnunyConfigurationException`, which still extends `RuntimeException`.

### Events

- `ZnunySessionRefreshed` now only carries `connection`. It was never dispatched in 0.1.
- Event payloads contain `[REDACTED]` for passwords and session IDs instead of omitting the keys.
- New optional properties: `ZnunyRequestSent::$method` and `$path`, `ZnunyResponseReceived::$status`, `ZnunyTicketUpdated::$dynamicFields`, `ZnunyArticleAdded::$articleId`.

### DTO serialization

`Ticket::toArray()` and `Article::toArray()` contain additional keys (`StateID`, `Owner`, `SLA`, … and `To`, `Cc`, `Bcc`, `IsVisibleForCustomer`, `Attachment`). If you return `toArray()` from an API, check your consumers.

### Webhooks

The `501` stub is replaced by a working endpoint. It stays disabled until `ZNUNY_WEBHOOKS_ENABLED=true` and rejects every request until `ZNUNY_WEBHOOK_TOKEN` (or Basic auth credentials) is set.
````
